# Claude Code guidance for summerfi-monorepo

@AGENTS.md

SDK documentation lives in `gitbook/` — regenerate with `pnpm docs:gen`, verify with
`pnpm docs:check`. Before hand-editing anything under `gitbook/` (or a TSDoc comment meant to
render there), read `sdk/docs/DOCS_PLAYBOOK.md` — it explains what's generated vs. hand-written and
the TSDoc tag rules TypeDoc actually enforces.
