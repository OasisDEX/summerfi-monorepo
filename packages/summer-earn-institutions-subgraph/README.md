# @summerfi/summer-earn-institutions-subgraph

GraphQL client library for the Summer Earn institutions subgraph. It wraps a `graphql-request`-based
SDK (generated by GraphQL Code Generator from `src/queries/queries.graphql`) and provides typed
query wrappers and a factory that returns one `SubgraphClient` per supported chain. Supported chains
are Base, Arbitrum, Mainnet, and Sonic, mapped in `src/utils/subgraphNameByChainMap.ts`.

## Key exports

- `getAllClients(baseUrl)` — returns a `Record<ChainId, SubgraphClient>` for every chain in
  `subgraphNameByChainMap`.
- `createClient(chainId, baseUrl)` (internal, not re-exported) — builds a single `GraphQLClient` for
  one chain and returns the generated SDK.
- Query wrappers from `src/wrappers/` — `getVaults`, `getHistoricalVaults`, `getInstitutions`,
  `getInstitutionById`, `getInstitutionVaults`, `getUserPositions`, `getUsersPositions`, `getUsers`,
  `getAllRoles`, and several `getRolesBy*` helpers.
- Types from `src/types.ts` — `SubgraphClientConfig`, `SubgraphClient`, `VaultsQuery`,
  `HistoricalVaultsQuery`, `Arks`, `Ark`.

## Scripts

| Command                       | What it does                                                                                                                                           |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `pnpm generate`               | Runs `graphql-codegen` (reads `codegen.yml`) and writes `src/generated/client.ts`. Requires `SUBGRAPH_BASE` set (loaded from `../../.env` via dotenv). |
| `pnpm tsc`                    | Compile TypeScript (emits to `dist/`).                                                                                                                 |
| `pnpm dev`                    | Incremental watch build via `tsconfig.build.json`.                                                                                                     |
| `pnpm test`                   | Runs Jest (passes if no tests are found).                                                                                                              |
| `pnpm lint` / `pnpm lint:fix` | ESLint.                                                                                                                                                |

> `build:disabled` exists in `package.json` but is intentionally skipped by Turbo.

## Cross-package connections

**Consumes**

**Consumed by**

- `external-api/get-protocol-info-function`
- `background-jobs/update-summer-earn-rewards-apr`

**Gotchas**

- `src/generated/client.ts` is auto-generated and not committed. Run `pnpm generate` after any
  `.graphql` change or after cloning. The codegen schema URL is
  `${SUBGRAPH_BASE}/summer-institutions-base`; `SUBGRAPH_BASE` must be present in `../../.env`
  (monorepo root `.env`).
- The `exports` field in `package.json` points directly at `src/index.ts`, so consumers resolve
  TypeScript source at dev time rather than compiled output.
