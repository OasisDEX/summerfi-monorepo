# @summerfi/app-earn-ui

Shared React component library and constants for the Summer.fi Earn protocol front-ends. It ships
atoms (`Box`, `Button`, `Text`, `Card`, `Icon`, `Input`, …), molecules (`Tooltip`, `Dropdown`,
`VaultCard`, `InputWithDropdown`, …), layout components (`Navigation`, `Footer`, `VaultGrid`,
`VaultManageGrid`, …), hooks, contexts, and protocol-level constants — all in a single ESM bundle
built with Vite. CSS Modules are compiled in parallel and their type declarations are generated by
`typed-css-modules` (`tcm`) as part of every build.

## Key exports / entry points

- **`src/index.ts`** — single barrel export; ~250 named exports covering all components, hooks,
  contexts, types, and helper functions.
- **`src/constants/supported-chains.ts`** — `supportedViemChains: Chain[]` (viem chain objects); the
  authoritative list of enabled networks.
- **`src/constants/swap-tokens.ts`** — `getSwapTokens(chainId: number)` function; returns the
  allowed token list for a given chain and controls which tokens appear in deposit/swap dropdowns.
- **`src/constants/earn-protocol.ts`** — protocol-wide constants including `networkWarnings`
  (per-network advisory messages) and `SUMR_CAP`.
- **`src/constants/icon-maps.tsx`** and **`src/helpers/network-icons.ts`** — exhaustive mappings
  from `SupportedNetworkIds` / `SupportedSDKNetworks` to network icon components.
- **`GlobalStyles`** — global CSS reset (includes `sanitize.css`); must be rendered once at the app
  root.

## Cross-package connections

**Consumes**

- `@summerfi/app-types` — `SupportedNetworkIds`, `SupportedSDKNetworks`, `TokenSymbolsList`, and
  other protocol types.
- `@summerfi/app-icons`, `@summerfi/app-token-config`, `@summerfi/app-utils` — icons, token
  metadata, utilities.
- `@summerfi/armada-protocol-common`, `@summerfi/summer-earn-rates-subgraph` — declared peer deps
  and marked `external` in `vite.config.ts`, but not currently imported by `src/`; consuming apps
  still provide them.

**Consumed by**

- `apps/earn-protocol` — primary consumer; imports `supportedViemChains` directly in
  `providers/WalletProvider/wagmi.ts` to build the Privy/wagmi config and per-chain HTTP transports
  at `/earn/api/rpc/chain/<id>`.
- `apps/earn-protocol-institutions` and `apps/earn-protocol-landing-page` — also declare this
  package as a workspace dependency.

**Gotchas**

- **Adding a new chain**: add the viem chain object to `supportedViemChains` in
  `src/constants/supported-chains.ts`; add icon mappings to `src/constants/icon-maps.tsx`
  (exhaustively keyed — TypeScript will error if a new `SupportedNetworkIds` /
  `SupportedSDKNetworks` value is missing) and `src/helpers/network-icons.ts` (uses `Partial`, so no
  compile error, but should be kept in sync); optionally add a `networkWarnings` entry in
  `src/constants/earn-protocol.ts`.
- **Adding a new swap token**: add the token symbol to the relevant per-chain array in
  `src/constants/swap-tokens.ts`.
- **CSS Module types**: `.module.css.d.ts` files are generated by `tcm` as part of `build`/`dev`. If
  you add or rename a CSS Module file, re-run `pnpm generate-module-types` before consuming the
  updated types.
- **Peer dependencies**: `react`, `viem`, `wagmi`, `next`, `@privy-io/react-auth`, and others are
  peers; the consuming app must provide matching versions.
