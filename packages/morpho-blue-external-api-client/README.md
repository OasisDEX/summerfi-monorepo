# @summerfi/morpho-blue-external-api-client

Thin GraphQL client for the Morpho Blue public API (`https://blue-api.morpho.org/graphql`). It
queries MetaMorpho vault details — APY figures, fee, total assets, and per-market supply allocations
— and normalises the raw API response into typed TypeScript interfaces. The package is used by
Lambda functions that need structured MetaMorpho vault data without coupling directly to the GraphQL
layer.

## Key exports

All exports are from the single entry point `dist/index.js` / `src/index.ts`:

- `getMorphoBlueApiClient(config: MorphoBlueApiConfig): MorphoBlueApiClient` — factory that returns
  the client object.
- `MorphoBlueApiClient` — interface with one method:
  `allocations(params: GetVaultDetailsParams): Promise<MetaMorphoAllocations[]>`.
- Data interfaces: `MetaMorphoAllocations`, `MetaMorphoVault`, `MetaMorphoVaultAllocation`,
  `MorphoMarket`, `MorphoAsset`.
- `MorphoBlueApiConfig` — accepts an optional `@aws-lambda-powertools/logger` `Logger` instance.

## Commands

```bash
# Codegen (must be re-run when schema.graphql or queries/*.graphql change)
pnpm generate-ts-types

# Build (runs generate-ts-types automatically via prebuild)
pnpm build

# Watch mode
pnpm dev

# Tests (exploration tests are skipped by default via describe.skip)
pnpm test

# Lint
pnpm lint
pnpm lint:fix
```

## Cross-package connections

**Consumes:**

- `@summerfi/serverless-shared` (workspace) — provides the `Address` type used throughout the
  interfaces.
- `graphql-request` — executes the GraphQL query against the Morpho Blue API.
- `@aws-lambda-powertools/logger` — optional structured logging passed in at construction time.

**Consumed by:**

- `summerfi-api/get-meta-morpho-details-function` — the only known consumer in this repo; imports
  `getMorphoBlueApiClient` directly.

**Gotchas:**

- `src/types/graphql/generated.ts` is auto-generated by `graphql-codegen` from `schema.graphql` and
  `queries/meta-morho-details.graphql`. It is **not committed** (covered by the root `.gitignore`
  pattern `/**/types/graphql/*.ts`) and must be generated before the first build, or re-generated
  whenever either source file changes (`pnpm generate-ts-types`). The `prebuild` hook runs this
  automatically on every `pnpm build`.
- No environment variables are required; the API URL (`https://blue-api.morpho.org/graphql`) is
  hard-coded in `src/index.ts`.
- The exploration test suite (`src/index.spec.ts`) is wrapped in `describe.skip` and is not executed
  on normal CI runs.
