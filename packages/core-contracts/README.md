# @summerfi/core-contracts

Solidity source, compiled ABIs, and deployment addresses for the legacy "operations" system — the
on-chain infrastructure (OperationExecutor, OperationStorage, OperationsRegistry, ServiceRegistry)
plus per-protocol actions (Aave, Ajna, Maker, Morpho Blue, Spark), swap helpers, and view contracts.
The TypeScript entry point (`src/index.ts`) exports a `Deployments` object that maps network keys
(`"Mainnet.standard"`, `"Base.standard"`) to their respective deployment address JSON files.

## Key exports / entry points

| Export path          | What it provides                                                                                |
| -------------------- | ----------------------------------------------------------------------------------------------- |
| `.` (root)           | `Deployments` object with Mainnet and Base contract addresses (auto-generated by deploy script) |
| `./abis/*`           | Raw ABI JSON files, mirroring the `contracts/` directory tree                                   |
| `src/lib/versions`   | `updateContractVersions`, `loadVersionsSnapshot`, and version-hash types used by `gen-versions` |
| `src/lib/deployment` | `deployAll`, `configureAll`, `verifyAll`, `addAllDependencies` — Hardhat deploy helpers         |

## Build / test / dev commands

```bash
pnpm build          # tsc -b --preserveWatchOutput tsconfig.build.json
pnpm dev            # tsc -b --preserveWatchOutput tsconfig.build.json -w  (watch)
pnpm test           # jest --passWithNoTests
pnpm lint           # eslint .
pnpm lint:fix       # eslint . --fix

# Hardhat scripts (require a configured network / RPC env vars)
pnpm deploy-contracts   # hardhat run scripts/deploy.ts
pnpm gen-versions       # hardhat run scripts/generate-versions.ts  — hashes contracts via @summerfi/contracts-utils getContractsHashes, updates src/versions/contracts-versions.snapshot.json
pnpm view-versions      # hardhat run scripts/view-versions.ts
```

## Cross-package connections

**Consumes (devDependencies):**

- `@summerfi/contracts-utils` — `getContractsHashes` called by `gen-versions` to hash Solidity
  artifacts into the snapshot
- `@summerfi/deployment-configs` — `loadDeploymentConfig` used in `deploy.ts`
- `@summerfi/deployment-utils`, `@summerfi/deployment-types` — chain/flag types for the deploy
  script
- `@summerfi/hardhat-utils` — `ChainsType` and Hardhat helpers
- `@summerfi/common` — the `Address` type imported by `src/lib/deployment/configuration.ts` and
  `verification.ts`
- `@openzeppelin/contracts 4.9.6`, `@prb/math 2.5.0` — Solidity library dependencies (pinned
  versions)

**Consumed by:**

- `@summerfi/sdk-server`, `@summerfi/order-planner-service`, `@summerfi/address-book-service`,
  `@summerfi/sdk-e2e` — all import deployment addresses from this package

**Gotchas:**

- `src/index.ts` is **auto-generated** by `deploy.ts`; hand-editing it will be overwritten on the
  next `pnpm deploy-contracts` run.
- `src/versions/contracts-versions.snapshot.json` is updated by `pnpm gen-versions` — re-run this
  after any Solidity change so downstream consumers see correct version hashes.
- Both `deploy-contracts` and `gen-versions` invoke Hardhat and require a live network RPC; they
  will fail without the appropriate environment variables set for the target chain.
